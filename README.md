
# Responsive Produce Gallery

A responsive image gallery developed as Ezitech Internship Task 1.

## Project Description

This project is a responsive gallery displaying fresh produce
images in three categories: Fruits, Vegetables, and Dairy.

## Features

- Responsive CSS Grid Layout
- Three category filters
- Nine sample images
- Interactive JavaScript filtering
- Desktop, tablet, and mobile responsive design
- No page reload when filtering

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Media Queries
- JavaScript
- Git
- GitHub

## Project Structure

responsive-produce-gallery/

- index.html
- style.css
- script.js
- README.md

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Click the category buttons to filter images.
